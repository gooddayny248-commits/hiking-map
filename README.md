# 산길 지도

미국 산(뉴저지·뉴욕 등)을 위한 **안드로이드 등산 지도 앱**입니다. 개인이 만들어 등산 친구들과 쓰는 앱입니다.

## 설치 파일 받기

**[➡ 산길 지도 설치 파일 받기 (SangilJido.apk)](https://github.com/gooddayny248-commits/hiking-map/releases/latest/download/SangilJido.apk)**

1. 안드로이드 휴대폰에서 위 링크를 누르면 설치 파일이 내려받아집니다.
   - 카카오톡 안에서 열었는데 안 받아지면, 화면 오른쪽 위 ⋮ → **다른 브라우저로 열기**를 누르세요.
2. 받은 파일(SangilJido.apk)을 눌러 설치합니다.
   - "출처를 알 수 없는 앱" 안내가 나오면 **허용**합니다. (구글 플레이 스토어에 없는 앱이라 나오는 안내입니다.)
3. 앱을 열고 **오프라인** 메뉴에서 지도를 받습니다.
   - **① 지도 받으러 가기** → 받을 지역 줄의 **Others Map** 버튼 → "산길 지도"로 열기
     - 뉴저지: Pensylv-NewJersey (약 520MB) / 뉴욕: NewYork-plus-east (약 930MB)
   - **② Elevate 스타일 받기** → **Default maps app** 버튼 → "산길 지도"로 열기
   - 와이파이에서 받으세요.

새 버전이 나오면 같은 링크에서 다시 받아 **기존 앱 위에 그대로 설치**하면 됩니다. 앱을 삭제하면 받은 지도와 기록이 지워집니다.

## 기능

- 오프라인 등산 지도 (OpenAndroMaps + Elevate 스타일), USGS 지형도, 위성 사진
- 내 위치와 고도, 산행 기록 (화면을 꺼도 기록, 거리·시간·오른 높이·고도 그래프)
- GPX 불러오기 / 내보내기, 경로 따라가기 (경로 이탈 알림)
- 지점 저장, 내 위치 공유, 지도 글자 크기 조절

## 알아 둘 점

- 아이폰에서는 쓸 수 없습니다.
- 지도와 지도 스타일은 앱에 들어 있지 않습니다. 각자 [openandromaps.org](https://www.openandromaps.org)에서 받으며, OpenAndroMaps 지도는 개인 사용에 한해 무료입니다.
- 기록과 받은 지도는 각자의 휴대폰 안에만 보관됩니다. 앱이 외부로 보내는 정보는 없습니다.
- 지도와 등산로는 실제와 다를 수 있습니다. 현장 표지와 공원 공식 지도를 함께 확인하세요.
